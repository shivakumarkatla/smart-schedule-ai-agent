# Example Interactions

## Calendar

**User**

> Schedule a project review tomorrow from 4 PM to 5 PM.

**Agent**

The agent identifies the requested time range and uses the Google Calendar tool to create the event.

## Email

**User**

> Send an email to Alex with the subject "Project Review" saying that the review is scheduled for tomorrow at 4 PM.

**Agent**

The agent extracts the recipient, subject, and message, then calls the Gmail tool.

## Combined workflow

A user can also make requests that require more than one action, where appropriate. The AI Agent determines which connected tool(s) are needed based on the request.
